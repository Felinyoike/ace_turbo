# Car Images Directory

This directory contains car images organized by make for the vehicle lookup results page.

## File Naming Convention

Images should be named using the lowercase make name with special characters removed:
- `audi.png` for Audi
- `bmw.png` for BMW
- `mercedesbenz.png` for Mercedes-Benz
- `volkswagen.png` for Volkswagen
- etc.

## Image Specifications

- **Format**: PNG, JPG, or SVG
- **Recommended Size**: 800x450px (16:9 aspect ratio)
- **Background**: Transparent or white
- **Orientation**: Side view of the vehicle preferred

## Adding Images

1. Find or create a high-quality image of the vehicle
2. Crop/resize to 800x450px (16:9 ratio)
3. Remove background if possible for a cleaner look
4. Save with the make name in lowercase (e.g., `audi.png`)
5. Place in this directory

## Fallback

If a specific make image is not found, the system will use `/images/car-placeholder.svg` which displays a generic car silhouette.

## Sources for Car Images

You can use:
- Stock photo sites (with proper licensing)
- Car manufacturer press kits
- AI-generated car images
- Your own photography
- Vector graphics/illustrations
